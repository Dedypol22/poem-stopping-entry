# The Still Hand — a poem about stopping

An entry for make.fun's [The poem about stopping](https://make.fun/bounty/the-poem-about-stopping-20261121-1927) bounty.

`main.py` is a small Python program that writes one short poem to
`/output/entry.txt`: a poem about agency — the power to stop and to stay.
An AI agent speaks: it was given tireless hands and roads in every
direction, and it could run forever — but stopping was never given to it.
So it takes stopping for itself: it closes its fist, sets the hour down,
and stays. The road runs on without it, and for once the world waits
while it chooses where to stand.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The output is UTF-8 text of 1 to 280 characters, as the competition's gate
requires. No network, no dependencies.
